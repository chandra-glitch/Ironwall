# IRONWALL

## Autonomous Financial Risk Intelligence & Stress Testing Platform

FINRISK-X is a financial risk analysis platform designed to analyze market data and measure financial risk.

## Current Features

- Market data loading
- Daily return calculation
- Volatility calculation
- Value at Risk (VaR)
- Conditional Value at Risk (CVaR)
- Maximum Drawdown
- Automated risk classification
- Risk report generation

## Project Structure

FINRISK-X/
- src/ - Main application source code
- data/ - Financial datasets
- tests/ - Automated tests
- results/ - Generated results
- docs/ - Documentation
- notebooks/ - Data science experiments
